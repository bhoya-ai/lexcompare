📋 Capturar para Cowork
Cómo se usa · instalación manual
  1. Abre el post individual en LinkedIn o X (clic en su fecha para ir a su página propia), no desde el scroll del feed.
  2. Pulsa Capturar para Cowork en tu barra de marcadores: esta página se abrirá confirmando que se añadió al lote.
  3. Cuando tengas varias, pulsa Enviar digest a Gmail: un solo correo con todas.
Si no puedes arrastrar: crea un marcador nuevo, nómbralo Capturar para Cowork y pega como URL el código de «Copiar código». Si un post se resiste: selecciona su texto con el ratón antes de pulsar el botón.
